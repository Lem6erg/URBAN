# URBAN — маршрути читання за задачею

Перевірено: 2026-11-27. Вхід — [README](README.md), шляхи — [карта](project_map.md),
контракти — [індекс](sources.md). Це маршрути дослідження, не дозвіл чіпати файли користувача.

## Перед кожним маршрутом

Правила [AGENTS](../../AGENTS.md) / [CLAUDE](../../CLAUDE.md) → гілка/diff →
релевантні пости [TODO](../../TODO.md) → конкретний код.
До зміни коду запиши Risk / Reason / Test strategy. Файли нижче — початок пошуку, а не повний перелік залежностей.

## 1. Digitals не читає / неправильно показує DXF

1. [Передача §3 «Digitals»](../urban_handoff_2026-11-27.md): R12, колір шару, cp1251, назви шарів.
2. [dxf_digitals](../../dxf_digitals.py) — запис R12, поділ шару за кольорами.
3. Перевірка: результат на копії → структура (POLYLINE/VERTEX, SOLID, шари) → підтвердження користувачем у Digitals.

## 2. Прив'язка «НЕ ВИЙШЛО» або зсув

1. [Передача §3 «Прив'язка»](../urban_handoff_2026-11-27.md): шари «1-x … Межі ділянок» ↔ «Земельна ділянка (JSON)», поріг 95 %.
2. [dxf_digitals](../../dxf_digitals.py) (ICP), [обгортка](../../dxf_digitals_drop.py) (пошук `ВД\Топо\*.dmf`).
3. Поріг не знижувати без рішення користувача (Risk HIGH).

## 3. DMF → DXF

1. [Передача §3 «DMF v1.15»](../urban_handoff_2026-11-27.md) — формат запису.
2. [dmf2dxf](../../dmf2dxf.py). CLI спільний із Кресляром ДПТ — не ламати.
3. Перевірка: копія DMF → DXF у scratchpad; кількість об'єктів, габарит, шари.

## 4. Системи координат і ключі

1. [Передача §3 «Системи координат»](../urban_handoff_2026-11-27.md): МСК-46, УСК-2000, СК-63 лише за пунктами.
2. [crs](../../crs.py), [crs_keys.json](../../crs_keys.json). Неофіційні параметри з форумів не брати.
3. Нова СК або зміна алгоритму — через Gate 0 → `/grill-me`.

## 5. Інтерфейс: текст, тема, іконки, вкладки

1. [dpt_converter](../../dpt_converter.py), [ui_icons](../../ui_icons.py).
2. Обмеження tkinter (без заокруглених кутів) і робота в потоці + черга — [передача §3 «Середовище»](../urban_handoff_2026-11-27.md).
3. Перевірка: запуск GUI в обох темах.

## 6. Інсталятор і запуск

1. [build.ps1](../../installer/build.ps1), [URBAN.iss](../../installer/URBAN.iss); BOM для `.ps1`/`.iss`.
2. Після правок коду інсталятор сам не оновлюється — збирати, якщо задача стосується видачі.

## 6а. Випуск нової версії / оновлення

1. [ТЗ оновлення](../urban_autoupdate_spec.md), [updater](../../updater.py), [release.ps1](../../installer/release.ps1).
2. `version.py` → `CHANGELOG.md` → коміт → `release.ps1` (лише за командою користувача).
3. Тести: `python -m unittest discover -s tests -v`; оновлення наживо — встановлена стара версія знаходить нову.

## 7. Нова функція або архітектурне рішення

Gate 0 лише читанням → `/grill-me` → DECISIONS LOCKED → ТЗ `Markdown/urban_<тема>_spec.md` → реалізація → TODO.

## 8. Передача між чатами

Знімок стану — `Markdown/urban_handoff_<дата>.md` (стан, факти, пастки, беклог, стартовий запит);
запис у TODO; посилання в [індексі](sources.md).
