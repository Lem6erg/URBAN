# Програма URBAN — передача в окремий проєкт

Складено 27.11.2026 з робочої сесії Кресляра ДПТ, де програму зроблено 27.11.2026 (поза роллю Кресляра). Цей файл — стартовий контекст для окремого чату/проєкту розробки програми. Оформлення ДПТ і роботу Кресляра сюди не переносити.

## 1. Що це

Настільна програма для Windows (Python + tkinter), яка готує файли між Archicad і Digitals:

| Розділ | Що робить |
|---|---|
| **Archicad DXF → Digitals** | DXF, експортований з плану поверху Archicad, автоматично прив'язує до топо DMF і пише DXF R12, який Digitals читає з шарами й кольорами. Можна кілька файлів. |
| **DMF → DXF** | Конвертує DMF Digitals у DXF R12 у тій самій системі; поруч пише CSV семантики й файл пікетів; опційно зсув до локального нуля для Archicad. DWG не пише (рішення користувача: DXF відкрити в CAD і зберегти як DWG). |
| **Ключ за пунктами** | Обчислює перехід між системами за спільними пунктами (Гельмерт 2D або афінне), показує нев'язки й СКП, зберігає ключ. Перевірено лише на синтетичних пунктах. |
| **Транслятор Archicad** | Покрокова інструкція підключення транслятора «07 Для Digitals (МСК)», шлях до нього, кнопки «Показати в папці» / «Скопіювати шлях». |

Також: автовизначення системи координат топо, шкала прогресу у %, світла/темна тема в стилі iOS (Авто / Світла / Темна), меню й іконки за зразком програми користувача ATLAS, лого користувача.

## 3. Технічні факти (перевірено)

**Archicad 29 → DXF**
- Archicad 29 не пише DXF R12 (найстаріша — AutoCAD 2000); R12 переписує скрипт.
- Список трансляторів Archicad не сканує папку: новий транслятор додається кнопкою «Найти...».
- Транслятор 07 = копія «01 Для дальнейшего редактирования» з: одиниці METER, R_2000, AlignBySurveyPoint, Drawings_To TO_MAIN_FILE, EXPLODE_ALL_COMPLEX_ELEMENTS, Layer_By APPL_LAYERS, ExportRGBIfNoMatch false, Splines_As_Splines false, SpecLayers порожні.
- Експортувати лише з вікна **плану поверху**, не з макета/робочого листа.
- Експорт має великий **непостійний** зсув (мільйони метрів; Y між експортами сталий, X різниться до ~1800 м); Точка зйомки його не прибирає. Причину не знайдено → лише автоприв'язка.

**Прив'язка (`dxf_digitals.py`)**
- ICP за найближчими вершинами: шари DXF «1-x … Межі ділянок» (існуючі) ↔ шар DMF «Земельна ділянка (JSON)»; проєктні «2-x» не використовуються (з ними 72 % → відмова).
- Запис лише якщо ≥95 % вершин збіглися до 1 мм; інакше «НЕ ВИЙШЛО», файл не пишеться. На тестовому об'єкті: 99,2 %.
- Враховує одиниці (INSUNITS) і зсув; поворот/масштаб не шукає.

**Digitals**
- Читає DXF R12 (POLYLINE/VERTEX, SOLID, cp1251) з шарами; бере **колір шару**, а не об'єкта → шар із кількома кольорами ділиться: «<шар> (колір C)».
- Назви шарів — як в Archicad, без «_Ном._пера__N».

**DMF v1.15** (для `dmf2dxf.py`): тіло zlib; кількість об'єктів int32 на зміщенні 14; рамка з 26; запис: 13×int32, атрибути, 4 байти, вершини по 34 байти (N, E, H як ext80 + 4 байти), 2 байти; в останньому записі бракує 6 байтів. Назви системи координат у DMF немає.

**Системи координат**
- МСК-46 (Львівська обл.) = EPSG:9851: TM, λ0 = 24°, k = 1, FE 300 000, FN 0, Красовський, датум УСК-2000. Тестове топо — МСК-46 (перевірено перерахунком у географічні координати в межах області).
- УСК-2000: 6° зони 4/5 — EPSG:5562/5563; 3° зони 7/8 — EPSG:5570/5571. Перерахунок між ними точний.
- СК-63: ключі закриті, у відкритому доступі немає; лише за спільними пунктами (3–6 точок у межах ~5 км). Неофіційні числа з форумів не брати.
- Автовизначення: середня точка топо перевіряється на потрапляння в Україну й у межі зони + назва файлу («МСК», «УСК», «СК-63»). СК-63 і умовні системи не визначає («НЕ ВИЗНАЧЕНО»); МСК різних областей за координатами не розрізнити.

**Середовище / Python**
- `python -I` ігнорує PYTHONIOENCODING → у скриптах `sys.stdout.reconfigure(encoding='utf-8')`; під `pythonw` stdout = None → перевіряти `if sys.stdout`.
- GUI: робота в потоці + черга; підпроцеси `Popen` з `-I -u`, прогрес — маркери в stdout + плавний «повзунок».
- tkinter не малює заокруглених кутів кнопок/полів.
- Файли з кирилицею для Inno Setup і PowerShell 5.1 (`.ps1`, `.iss`) — UTF-8 з BOM.
- Git Bash heredoc псує `\n`/`\t` → патчі писати інструментом Write або Edit.

## 4. Помилки, які вже траплялися

- Тест програми **видалив файл користувача** «проектовані межі ділянок (МСК, Digitals).dxf» (відновлено). Виправлено: проміжний файл — у TEMP, наявні файли не чіпати. Правило: тестувати на копіях, тестові результати прибирати, файли користувача не перезаписувати.
- Рекурсивний `transformer` зависав → ланцюжок переписано без рекурсії.
- Прямий запис DMF → помилка в Digitals → лише DXF R12.
