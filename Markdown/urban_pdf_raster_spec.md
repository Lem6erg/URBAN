# ТЗ: PDF → JPEG / TIFF (2026-11-27)

Нове меню «ЗОБРАЖЕННЯ → PDF → JPEG / TIFF»: якісне перетворення сторінок PDF (аркуші ДПТ, скани) у растр.

## DECISIONS LOCKED

Рішення користувача (2026-11-27):
- **Р1. Якість — три рівні:** Чернетка, Друк, Максимум. Без тонких налаштувань.
- **Р2. TIFF — кожна сторінка окремим файлом.**
- **Р3. TIFF — стиснення LZW (без втрат) + вибір кольору:** кольоровий / відтінки сірого / чорно-білий (для Ч/Б — CCITT Group 4).
- **Р4. Список PDF + діапазон сторінок** («усі» або «1-3,5»). Результат — у папку поруч із PDF «<назва> (JPEG)» / «<назва> (TIFF)». Наявні файли не перезаписуються.

Рішення агента:
- **Р5. Рушій — pypdfium2** (PDFium, як у Chrome; ліцензія Apache-2.0/BSD-3). PyMuPDF не беремо: AGPL. Poppler не потрібен.
- **Р6. Рівні:**

  | Рівень | DPI | JPEG |
  |---|---|---|
  | Чернетка | 150 | якість 85 |
  | Друк | 300 | якість 95, без проріджування кольору (4:4:4) |
  | Максимум | 600 | якість 100, 4:4:4 |

  DPI записується в метадані файла.
- **Р7. JPEG:** кольоровий або відтінки сірого. Чорно-білий режим — лише для TIFF (JPEG для Ч/Б непридатний).
- **Р8. Ч/Б** — поріг 50 % без розсіювання (dithering), щоб лінії креслень були чисті.
- **Р9. Ліміт пам'яті:** сторінка понад 150 Мп (напр. A0 при 600 DPI) рендериться зі зниженим DPI, у журналі — попередження. Для JPEG сторона ≤ 65 000 px.
- **Р10. Імена:** `<назва>_с01.jpg` (нулі — за кількістю сторінок). Якщо файл уже є — `<назва>_с01 (2).jpg`.
- **Р11. Анотації й поля форм** малюються (як на екрані). Біле тло. PDF з паролем — зрозуміла помилка, інші PDF списку обробляються далі.
- **Р12. Робота** — у фоні, загальна шкала прогресу (за сторінками), журнал.

## Модулі
- `pdf_raster.py`: без tkinter. `parse_pages(text, n)`, `LEVELS`, `convert(pdf, fmt, level, color, pages, progress, log)` → список записаних файлів.
- `dpt_converter.py`: сторінка `p6`.
- `tests/test_pdf_raster.py`: синтетичний PDF (створений у тесті), без даних замовників.
- `installer/build.ps1`: збирати pypdfium2 разом з PDFium.
