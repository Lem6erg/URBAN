URBAN — як підключити транслятор Archicad «07 Для Digitals (МСК)»

Файл транслятора встановлено разом із програмою:
  <папка URBAN>\Транслятор Archicad\07 Для Digitals (МСК).Xml
  (за замовчуванням: C:\Users\<ім'я>\AppData\Local\Programs\URBAN\Транслятор Archicad)
Швидко відкрити цю папку: меню «Пуск» → «URBAN — транслятор Archicad»,
або в програмі URBAN — вкладка «Транслятор Archicad» → «Показати в папці» / «Скопіювати шлях».

Підключення в Archicad (один раз):
  1. Меню «Файл → Взаимодействие → DXF-DWG → Параметры Трансляции DXF-DWG…»
     (англ. File → Interoperability → DXF-DWG → DXF-DWG Translation Setup…).
  2. У вікні трансляторів натисніть «Найти…» (Browse…) і виберіть файл
     «07 Для Digitals (МСК).Xml» з папки, указаної вище.
  3. Транслятор з'явиться в списку — натисніть «Готово».
     Файл не переносьте й не видаляйте: Archicad бере його з цієї папки.

Експорт DXF для Digitals:
  4. Відкрийте ПЛАН ПОВЕРХУ (не макет) → «Файл → Сохранить как…» → тип «DXF»
     → транслятор «07 Для Digitals (МСК)».
  5. Отриманий DXF додайте в URBAN, вкладка «Archicad DXF → Digitals» → «Перетворити».
     Програма прив'яже креслення до топо (DMF з папки ВД\Топо об'єкта), збереже кольори
     шарів і запише DXF R12, який Digitals відкриває з шарами Archicad.
